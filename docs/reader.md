# 科研阅读器运行时

## 组件与加载

科研阅读器是可选组件 `dsh-zotero/reader`，默认关闭。启用后，宿主注册 `zotero.reader*` 端点，浏览器注册独立的右侧「文档阅读」标签页。打开标签页时加载 Reader UI；打开 PDF 时再加载 PDF 运行时和 Worker。两个包内 chunk 分别为 `client.reader-ui.js` 与 `client.reader-pdf.js`，启动包不包含 PDF.js。阅读位置、历史与翻译缓存只属于当前浏览器，Zotero 保存标注和笔记。

PDF 运行时基于 PDF.js 6.3.289（Apache-2.0），使用公开的 `PDFViewer`、`EventBus`、`LinkService`、`FindController` 和 Worker。页面渲染在封闭的 Shadow DOM 中；宿主样式表与 `:focus-visible` 规则不能跨边界生效。构建在 PDF.js 样式表之后追加一段只引用 `--dsw-*` 别名的影子主题，为选区、查找命中、批注弹窗、焦点环和标注覆盖层取色。`tests/unit/tooling/reader-shadow-theme.spec.ts` 拒绝该段出现颜色字面量或私有色板。`scripts/build-client.mjs` 检查启动包、Reader UI 与 PDF 运行时的工厂；`npm run smoke:reader-pdf` 用合成 PDF 验证打包后的运行时和 Worker。

## 文档类型与读取路径

| 类型        | 来源与读取方式                                                 | 边界                                                                                              |
| ----------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 本地 PDF    | 通过宿主 Workspace Files Remote 按会话权限读取已解析的附件路径 | 读取权限与取消由宿主执行；关闭标签页释放文件                                                      |
| URL PDF     | 沿用文献面板的 `allowUrlPdfRead` 授权、下载门与租约            | 关闭后释放租约；Reader 不可用时回退宿主原生预览                                                   |
| HTML 快照   | 重建为无活动内容的元素；脚本、表单、远程资源不执行             | 最多读取 512 KiB UTF-8，达到上限时提示只显示部分内容                                              |
| Markdown    | 使用 Harness 渲染器；原始 HTML 省略，图片以替代文字呈现        | 同上                                                                                              |
| 纯文本      | 按 UTF-8 解码并保留换行                                        | 同上                                                                                              |
| Zotero 笔记 | `readerNote` 返回限长 HTML、当前版本和可编辑文本片段           | 最多 256,000 个 UTF-16 代码单元的 HTML 与 16,000 个代码单元的纯文本；本地图片按需读取，单张 2 MiB |

Reader 以附件 ref 和实例、文库、条目、文档类型及可验证的内容版本划分阅读状态和索引。文件内容或来源代际变化时，衍生缓存失效。文本文档的查找不区分大小写，可跨内联格式匹配，每个附件最多绘制 1,000 个高亮结果；选区引用携带渲染文本的半开 UTF-16 范围和完整读取时的 SHA-256 指纹。切换同一条目的 PDF 时重新解析附件，各附件保留自己的阅读状态。

## 阅读状态与历史

浏览器保存页码、页内偏移、缩放、适应模式、旋转、目录与详情面板布局、累计阅读时间和上次访问时间。持久化关闭时不保存阅读位置，也不显示最近阅读。历史默认保留 50 条，可在设置中设为 1–500；序列化快照超过 1,000,000 个 UTF-16 代码单元时整体拒绝。只有带服务器限定符的附件 ref 能进入快照；存在父条目 ref 时，还要求两者属于同一实例和文库。文献列表按已核验的父条目 ref 显示上次阅读时间。Harness 阅读标签页与浏览器页面同时可见时才累计阅读时间。`tests/client/reader/reading-history.spec.ts`、`ReaderTab.history.spec.tsx` 与 `tests/client/library/reading-visits.spec.tsx` 分别验证存储、计时和列表更新。

## 标注、坐标与证据

PDF 坐标由 PDF.js viewport 转换，显示时处理 CropBox、旋转与缩放。跨页选区保留逐页几何，再按物理页各生成一条 Zotero 高亮或下划线；每页最多 1,024 个矩形，位置 JSON 不超过 65,000 个字符。编辑与删除携带界面所显示的版本；审批后领域层在锁定的 Zotero 实例中核对类型与版本，冲突时刷新列表。标签变更与标量编辑在同一次版本化 PATCH 中提交，删除使用单条目版本化 DELETE。`tests/local/write/annotations.spec.ts` 与 `tests/host/write/reader-annotations.spec.ts` 验证请求、过期版本和部分回执。

EvidenceAnchor 记录文档身份、来源类型、物理页索引、印刷页码、章节路径、原文、上下文、矩形、文本范围、内容指纹和精度。定位依次尝试几何、上下文消歧文本、页、章节和文档；多个候选位置交给用户判断。文献轨迹把物理页索引和矩形传给 Reader，Reader 跳到对应页并绘制临时、不可交互的证据区域；清除目标或页面重绘后移除该层。没有几何位置的片段用预览文本定位当前 PDF。MinerU 产物只在附件指纹与版本相符时参与定位。相关契约与并发边界见[系统架构](architecture.md)。

## 预算与上限

| 项目           | 上限                                   | 说明                                                 |
| -------------- | -------------------------------------- | ---------------------------------------------------- |
| PDF 全文摘录   | 32 个物理页、16,000 个 UTF-16 代码单元 | 预览显示截短提示与无法提取文字的页数                 |
| 文本文档读取   | 512 KiB UTF-8                          | 超出时显示部分内容提示                               |
| 文档查找高亮   | 1,000 个结果                           | 每个附件独立计数                                     |
| 会话模型翻译   | 8,000 个输入代码单元、30 秒            | 输出上限 32,000 个代码单元；本地翻译结果缓存在标签页 |
| 模型标注建议   | 1,000 个输出代码单元                   | 建议先显示，接受后才进入可编辑评论                   |
| 批量引用       | 8 条条目、每条 1,500 个代码单元        | 格式化后的整条引用最多 16,000 个代码单元             |
| 区域截图       | 4,000,000 像素、单边 4,096             | 区域文字最多 16,000 个代码单元                       |
| 浏览器笔记草稿 | 每标签页 16 条                         | 存储不可用时只在内存保留                             |

## 宿主边界与兼容性

Reader 的读取端点要求当前会话具有来源访问权限；标注、笔记和回答笔记写入仍走核心能力门、会话审批与计划审查。锁定的 Harness 在空闲会话中拒绝写入审批，Reader 保留待提交的编辑或删除确认和本地草稿。Reader 通过 `sidebarRightTabs`、`sidebar.right.pane.tab`、`conversation.chat.turnTail` 与设置页插槽组合；从文献面板、文献轨迹和已完成轮次打开附件。宿主验证条目类型后返回笔记内容；外部链接和图片保持惰性。

兼容基线为 `package.json` 锁定的 Harness 与 Zotero Local API：读取支持 Zotero 7 及以上，写入支持 Zotero 10 及以上，原生标注与笔记 CRUD 在隔离的 Zotero 11.0-beta.5 上验证。发布流程在 Linux 用 Chromium、Firefox 和 WebKit 验证安装包的 PDF 运行时，在 macOS 与 Windows 用 Chromium 验证。浏览器本地翻译依赖 Translator 与 Language Detector API 及对应语言包；会话模型翻译使用当前会话选择的模型。Reader 直接向 Composer 添加生成的图片，依赖 Harness 提供公开的文件注册入口；当前公开输入操作接受已注册的草稿附件 ID。设置字段见[配置参考](configuration.md)，用户操作与限制见[功能概览](features.md)，构建与浏览器验收命令见[开发指南](development.md)。
