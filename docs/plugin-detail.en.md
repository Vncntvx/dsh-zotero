- Core component (`dsh-zotero`): Local Zotero connection, 8 read tools, 15 write tools (off by default; writes require plan review card confirmation), literature trail, and settings page.
- Literature panel (`dsh-zotero/library`): Right-sidebar tab covering full-library navigation (collection tree, saved searches, My Publications, Trash), item list filtering, item inspection, citation copying (CSL citation, BibTeX, bibliography, BibLaTeX, RIS, CSL-JSON, and item info), and approved controlled writes.
- Scholarly search (`dsh-zotero/scholarly`): External literature retrieval component, off by default. Enabling it registers 7 scholarly tools covering arXiv, OpenAlex, Crossref, Semantic Scholar, PubMed, Europe PMC, and DBLP, with full-text reading, citation graphs, reference verification, and saving to Zotero. The client displays a request scope notice when first enabled.
- Document parsing (`dsh-zotero/enrichment`): Optional component, off by default. Supports user-submitted PDF parsing via MinerU, reuse of existing Markdown artifacts, and local semantic ranking with embedding model management. The client displays an egress notice when first enabled. Supports token-free `free` and token-gated `pro` parsing, saving Markdown artifacts to a configured directory.
