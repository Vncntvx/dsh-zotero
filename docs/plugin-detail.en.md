- Core component (`dsh-zotero`): the local Zotero connection, 8 read tools and 15 write tools (off by default; once enabled, every write needs confirmation on the plan review card), the literature trail, and the settings page.
- Literature panel (`dsh-zotero/library`): a right-sidebar tab covering whole-library navigation (collection tree, saved searches, My Publications, Trash), item list filters, item inspection, citation copying (CSL citation, BibTeX, bibliography, BibLaTeX, RIS, CSL-JSON, and item info), and approved controlled writes.
- Scholarly search (`dsh-zotero/scholarly`): the external literature retrieval component, off by default; mounting the component is what authorizes requests to the external academic indexes. It covers arXiv, OpenAlex, Crossref, Semantic Scholar, PubMed, Europe PMC, and DBLP, with full-text reading, citation graphs, reference verification, and saving to Zotero.
