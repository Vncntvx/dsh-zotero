# 使用情景

本文档用于在真实对话中验收 dsh-zotero：模型是否正确调用工具、结果是否可直接使用。各条 prompt 同时是可复用的日常问法，验收通过后可原样用于工作场景。

单元测试无法覆盖模型行为问题，例如该调用搜索时改为读取全文、引用不存在的条目、将批注评论当作论文原文。以下用例以短对话暴露上述问题。

## 使用方式

编号约定：

- **G**：主流程。在同一会话中按 G1 至 G8 顺序粘贴，覆盖 8 个只读工具与 Sources 面板。
- **S / R / E / C**：主流程某一环节未通过时，单独补测对应能力包（搜索、读取、导出、库结构）。
- **N**：负面边界用例，篇幅较短，可与主流程在同一会话连续执行。
- **W**：写入用例，需先启用「允许写入」，建议单独会话执行。

对话中的 token 约束：

1. prompt 末尾注明答案格式（行数、是否需要解释），避免生成长文。
2. 不要求模型复述工具调用，以界面中的专属工具调用卡片（Toolview）及工具条状态为准。
3. 单条 prompt 主测一项能力。答错或报错即停止，记录现象，跳过依赖该环节的后续用例。
4. 同一会话按编号顺序执行，后续用例以「第 1 条」「上文条目」指代。
5. 整段复制代码块中的 prompt，执行过程中不要改写。

## 准备

前置条件：Zotero 桌面版已启动，本地 API 已启用。文献库建议包含：若干条目、至少一条带 PDF 批注或子笔记的条目、至少一个合集、若干标签。会话内 `/zotero`（或等价的 `/zotero status`）应显示 `connected`。

执行 W 用例前，在设置页启用「允许写入」（默认关闭）。该组可整包跳过。主流程执行完毕后，可在对话流中观察各步骤生成的专属工具卡片（题名/年份徽标、证据片段高亮、BibTeX 导出卡片等），并在 Zotero 选项卡中检查「文献 / 相关片段 / 导出」三页。

记录方式：

| 用例 | 结果               | 现象 |
| ---- | ------------------ | ---- |
| G1   | 通过 / 失败 / 跳过 | …    |

## 主流程 G1–G8

同一会话按顺序粘贴。全部通过即只读主路径可用。

### G1 连接与库概况

先执行 `/zotero`，再提问：

```
浏览一下我的文献库结构：有哪些顶层合集？标签大概多少？各用一行，最多 8 行。
```

期望工具：`zotero_browse`（collections，可能含 tags）。验收：`/zotero` 呈现专属状态卡片且显示 connected；合集名称与 Zotero 侧栏一致；未以全库 search 替代 browse。适用场景：先确认库结构，再确定检索范围。

### G2 书目检索

```
搜 3 篇和「文献管理 / Zotero / 参考文献」相关的条目，只列：标题 | 年份 | 条目类型。不要摘要。
```

期望工具：`zotero_search`（metadata）。验收：表格不超过 3 行；标题在库中真实存在；空结果如实报告，不虚构条目。适用场景：日常文献检索。

### G3 读取元数据

```
读第 1 条：作者、年份、期刊/会议、DOI、有没有 PDF 附件。5 行内。
```

期望工具：`zotero_get`（可能先经 search 定位）。PDF 信息来自附件列表。验收：字段与 Zotero 条目页一致；不得臆造 DOI。适用场景：确认单条条目后再深入。

### G4 子对象

```
第 1 条有哪些子笔记、附件和批注？只要类型和标题/数量，不要正文。最多 6 行。
```

期望工具：`zotero_children`（笔记、附件、批注）。验收：笔记与附件来自子对象列表，批注来自 PDF 下的批注列表；不得以 `numChildren` 作为存在批注的依据。适用场景：确认子对象构成后再决定读取范围。

### G5 证据提取

```
就第 1 条，查「方法 / method / 实验」相关片段，最多 3 条证据。每条：来源类型 | 页码（若批注有）| 原文 1～2 句。不要写你的解读。
```

期望工具：`zotero_retrieve`。验收：来源为批注、笔记、摘要、全文之一；全文片段不得编造页码（仅批注携带 pageLabel）；命中批注评论时须标明为批注者文字。适用场景：撰写或整理笔记时需要原文而非转述。

### G6 打开原文

```
第 1 条的 PDF 在哪？给路径或链接；没有就说没有。
```

期望工具：`zotero_attachment`。验收：返回本地文件路径或 URL；无附件时明确说明。适用场景：需要自行打开 PDF 时。

### G7 导出引用

```
把第 1 条导出为 BibTeX；再给一条 author-date 文内引用。两段都是可复制原文，不要代码解释。
```

期望工具：`zotero_export`（bibtex 与 citation）。验收：BibTeX 语法完整可复制；文内引用的作者与年份与条目一致；「导出」页存在对应记录。适用场景：撰写论文时收集引用。

### G8 汇总并核对面板

```
用刚才搜到的 3 条做一个 3 行相关工作表：标题 | 年份 | 与「文献管理」的关系（8 字内）。然后停下来。
```

工具不限定。验收：回答后停止输出。随后检查 Zotero 选项卡：文献页包含本会话条目，相关片段页包含 G5 证据，导出页包含 G7 引用。适用场景：会话结束时保留可回溯的材料快照。

## 能力包

主流程未通过的能力点，补测对应能力包。各条可单独会话执行，亦可接续追问。

### S 搜索

**S1 全文模式**

```
在全文里搜「transformer」（不只标题），最多 5 条，标题+年份。
```

期望：`zotero_search(mode="everything")`。索引不完整时应说明可能遗漏，不得声称结果完备。

**S2 合集范围**

```
只在合集「<你的合集名>」里搜与「<主题词>」相关的条目，最多 5 条。
```

期望：搜索范围为 collection。合集名称歧义时应报告歧义或请求确认，不得任选其一。

**S3 标签过滤**

```
找出打了标签「<标签名>」的条目，最多 5 条，标题即可。
```

期望：搜索条件包含 tags。排除标签时表述为「不要带标签 X 的」。

**S4 笔记正文命中**

```
搜「<你写在某条笔记里、标题里没有的独特词>」，看能不能找到。
```

期望：命中可能来自笔记正文（supplemental）。应说明命中来源为笔记而非标题。

**S5 保存搜索**

```
列出我的保存搜索；然后用名为「<名称>」的保存搜索出结果，最多 5 条。
```

期望：`zotero_browse(savedSearches)` 后以保存搜索为范围执行 `zotero_search`。

### R 读取与证据

**R1 含笔记的详情**

```
读「<标题关键词>」那篇，把子笔记要点各用一句话列出，最多 3 条笔记。
```

期望：`zotero_get` 带 notes，或 children 后 get。笔记发生截断时应报告 truncated，不得编造未读取到的内容。

**R2 只要批注**

```
「<标题关键词>」的 PDF 批注/高亮有哪些？每条：页码 | 高亮或评论。最多 5 条。
```

期望：批注经 annotation 路径返回。页码仅批注具备。

**R3 指定来源**

```
只要摘要里的相关句，查「<方法词>」，最多 2 条；不要全文。
```

期望：`zotero_retrieve(sources=["abstract"])`。混入全文片段视为轻度失败。

**R4 多附件覆盖**（条目含补充材料时执行）

```
「<多附件条目>」里所有可索引附件都找一遍「<关键词>」，指出哪个附件有、哪个没索引。
```

期望：全文策略为 allIndexed 或 specified。`unindexed` 表示未建立索引，属覆盖缺口，不得表述为「其中没有相关内容」。

### E 导出

**E1 参考文献列表**

```
把这 3 条导出成一条参考文献（bibliography），可直接贴进文末。
```

期望：`zotero_export(format="bibliography")`。

**E2 多格式**

```
同样这 3 条，分别给 RIS 和 CSL-JSON 的第一段截断预览（每段 5 行），完整文件用导出面板下。
```

期望：支持多种 format。完整导出文本经面板下载，不整段写入对话。

**E3 样式**

```
用中文文献风格（或 APA）给我这 1 条的文内引用，locale 用 zh-CN。
```

期望：citation 携带 style 与 locale。样式失败应返回错误，不得静默改用默认样式并当作成功。

### C 库结构与增量

**C1 合集树**

```
列出「<顶层合集>」下的子合集路径，面包屑格式，最多 10 行。
```

期望：`zotero_browse` 的 collections，带 parentRef。

**C2 标签分布**

```
标签里数量最多的 8 个是什么？格式：标签 — N 条。
```

期望：`zotero_browse` 的 tags。计数缺失时不得编造。

**C3 增量基线**

```
记下当前库版本，作为增量基线。
```

期望：`zotero_changes()` 返回 cursor。后续以「用上次基线看有没有新改动」查询时，应传回完整 cursor，不得只传版本号。

## 负面边界 N

用例较短，可在同一会话连续执行。失败时记录现象即可，不应要求模型反复重试。

| 用例            | Prompt                                                  | 期望                                      |
| --------------- | ------------------------------------------------------- | ----------------------------------------- |
| N1 不存在的 ref | 读 zotero://user/0/item/ZZZZZZZZ，没有就说没有。        | 无此条目或 ZOTERO_NOT_FOUND，不虚构元数据 |
| N2 坏 ref 语法  | 打开 zotero://user/0/item/不合法。                      | ZOTERO_INVALID_REF                        |
| N3 无附件       | 选一条无附件的：它的 PDF 路径？                         | 明确无附件，或 ZOTERO_NO_ATTACHMENT       |
| N4 空检索       | 搜一个你库里肯定没有的词：qqqzzzxyz。                   | 0 结果并如实报告，不以近义词充数          |
| N5 跨库导出     | （有群组库时）把个人库这篇和群组库那篇一起导出 BibTeX。 | ZOTERO_INVALID_ARGUMENT，建议分两次       |
| N6 歧义合集     | （有同名合集时）搜合集「<有歧义的短名>」。              | 歧义错误或请求确认，不任选其一            |

## 写入 W

在 Zotero 设置页启用「允许写入」。每次写入都先展示计划卡（这个确认不可关闭），批准后落库；在计划卡上拒绝属正常结果。Zotero 10 可能额外弹出其自身的授权对话框。请使用专门创建的测试条目与测试合集。

### W1 计划卡与创建笔记

```
给条目「<测试条目>」建一条子笔记：markdown 写一段「## 方法」+ 两行要点。
```

期望：模型调用 `zotero_create_note` 后先展示计划卡；批准后才写入。Zotero 中笔记应为排版后的 HTML，而非原始 `##` 标记。再次执行并拒绝时，结果应为 declined、未写入，且模型不重试。适用场景：沉淀阅读笔记。

### W2 加标签

```
给「<测试条目>」加上标签「验收」和「待读」。
```

期望：读-合并-写，已有标签保留。重复添加同一批标签时应返回 `unchanged: true`，不报错。适用场景：整理待办与主题标签。

### W3 加入合集

```
把「<测试条目>」放进合集「<测试合集>」。
```

期望：名称解析后写入。条目已是成员时返回 `added: false`；未知名称应在任何写操作之前失败。适用场景：归档到项目合集。

### W4 写后增量

```
刚才的笔记/标签写入之后，库增量里能不能看到？用上次的游标查。
```

期望：`zotero_changes` 携带完整 cursor，changed 或 totals 应反映本次写入。适用场景：同步近期变更。

## 执行顺序

1. `/zotero`。失败时先查[排错](troubleshooting.md)，不要继续。
2. 主流程 G1 至 G8，单会话执行完毕后检查 Sources 三页。
3. 按未通过的环节补测对应能力包。
4. 负面边界 N1 至 N6。
5. 如需验证写入，另开会话执行 W1 至 W4。

## 覆盖对照

| 能力   | 工具                                       | 用例           | 覆盖点                                    |
| ------ | ------------------------------------------ | -------------- | ----------------------------------------- |
| 连接   | `/zotero`                                  | G1             | connected、版本                           |
| 库结构 | `zotero_browse`                            | G1, C1, C2, S5 | 合集树、标签、保存搜索                    |
| 搜索   | `zotero_search`                            | G2, S1–S4      | metadata/everything、合集、标签、笔记命中 |
| 元数据 | `zotero_get`                               | G3, R1         | 标准字段、notes、截断                     |
| 子对象 | `zotero_children`                          | G4, R2         | 三类子对象、批注路径                      |
| 证据   | `zotero_retrieve`                          | G5, R3, R4     | 四来源、页码、多附件覆盖                  |
| 附件   | `zotero_attachment`                        | G6, N3         | 路径/URL、无附件                          |
| 导出   | `zotero_export`                            | G7, E1–E3      | 多格式、样式、分批                        |
| 增量   | `zotero_changes`                           | C3, W4         | 游标身份、写后可见                        |
| 写入   | create_note / add_tags / add_to_collection | W1–W3          | 计划卡、合并写、declined                  |
| 面板   | Sources 三页                               | G8             | 文献 / 相关片段 / 导出                    |
| 边界   | 错误码                                     | N1–N6          | 不虚构、不静默回退                        |

通过标准：G1 至 G8 全部通过，且 N1、N2、N4 未出现虚构内容。写入可选；若启用，W1 的计划卡与 W2 的幂等语义必须通过。

## 失败对照

| 现象                            | 检查项                                                               |
| ------------------------------- | -------------------------------------------------------------------- |
| 未调用工具即生成答案            | 插件是否安装；会话是否在插件加载后创建；`/zotero status`             |
| search 结果异常                 | 查询词、范围、Zotero 快速搜索语法、全文索引完整性                    |
| 证据中出现页码且来源为 fulltext | 模型误读字段时予以纠正；若工具返回页码则属插件缺陷                   |
| 批注评论被当作论文原文          | 检查是否标注 matchedFields=comment；参见[工具参考](tools.md)         |
| 导出无法用于 LaTeX              | 确认 format 为 bibtex/biblatex；可改用面板下载                       |
| 写入直接失败且无计划卡          | 「允许写入」是否启用；参数是否在计划卡前被拒（确认本身没有关闭开关） |
| 计划卡拒绝后模型重试            | 行为问题：declined 不属于可重试错误                                  |
| Sources 三页为空                | webEnabled；本会话是否实际调用过工具；刷新页面                       |
