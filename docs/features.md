# 功能概览

dsh-zotero 把 Zotero 文献库接入 DSH。Agent 在对话中检索、阅读、引用文献，并可按需写入；你在文献面板中浏览整个库、复制引用；文献轨迹集中展示当前会话查到的文献、提取的原文片段和导出内容，便于核对。三者的分工见[产品模型](product-model.md)。

## 在对话中检索与研读

Agent 有 8 个只读工具，参数和错误码见[工具参考](tools.md)。

- `zotero_search` 默认匹配标题、作者和年份，`everything` 模式连全文索引一起搜。范围可以是整个库、个人出版物、某个合集或某个保存的搜索。第一页会顺带扫笔记正文，命中的笔记条目单列在 `supplemental` 里，不计入分页总数。
- `zotero_browse` 读合集树、标签列表和保存的搜索，单页条数受 `maxBrowseResults` 约束，响应携带总数与游标。
- `zotero_get` 返回标题、作者、年份、期刊、DOI、URL、摘要和独立的 `citationKey`；citekey 来源冲突会显式标记。加上 `include` 可以取子笔记正文、PDF 批注和附件列表。
- `zotero_get_batch` 按输入顺序批量读取最多 50 个已知 ref，每条结果独立报告；单条读取仍用 `zotero_get`。
- `zotero_match_references` 用 DOI、BibTeX 键和文献指纹与本地库对账，返回 ref、citekey、置信度和可审阅的字段差异；citekey 冲突时显式标记差异。
- `zotero_retrieve` 从批注、笔记、摘要和全文索引里找片段，用 BM25 词频排序。每条片段带来源和页码标签，页码只有批注才有，取自 Zotero；命中落在正文还是批注评论会标出来。全文覆盖度放在 `coverage`，没建索引或读不到的来源记进 `sourcesSkipped`，附件状态分 `indexed`、`unindexed`、`unread`。
- `zotero_export` 支持六种格式。除 `citation` 外，单次最多 50 篇，这是 Zotero `itemKey` 的请求上限；`citation` 按 50 一组分批。

  | 格式                  | 输出                                       |
  | --------------------- | ------------------------------------------ |
  | `citation`            | 逐条 HTML 引用，按输入顺序                 |
  | `bibliography`        | CSL 排序的合并参考文献表                   |
  | `bibtex` / `biblatex` | BibTeX / BibLaTeX 词条，能定位每条的引用键 |
  | `ris` / `csljson`     | RIS 文本 / CSL-JSON                        |

  样式和语言默认取配置里的 `defaultStyle` 和 `defaultLocale`，可以用 `style`、`locale` 覆盖。

- `zotero_changes` 从本地库版本号出发，报告新增、修改和删除，回收站单独算一块。

工具结果在对话中以只读卡片呈现：折叠时显示一行摘要，展开后按工具类型显示条目、片段、导出文本或回执，并提供复制和「阅读 PDF」操作。

研究 SOP 技能提供八个按需研究流程：单篇速读、主题版图、引文脉络、证据比较、写作对账、文库治理、真伪审查与文献入库。模型先从只含名称与短描述的目录中选择，再经 `skill` 工具加载完整分阶段指令；正文不进入常驻 system prompt。详见[研究 SOP 技能参考](skills.md)。

## 核对文献轨迹

文献轨迹在会话顶部，按条目聚合当前会话中检索与读取的文献。数据来自宿主按完整会话日志折叠的会话投影，长会话也能保留早期条目；投影不可用时使用当前窗口的工具调用快照。

文献轨迹记录读类工具与导出的结果；写入操作由审批卡独立记录；学术检索结果保存入库后进入轨迹。

每次检索的条件直接摆在首屏：查询词、范围（库、个人出版物、合集、保存的搜索）、模式（元数据或全文）、筛选（条目类型、标签、回收站），以及返回条数和总数。扫过笔记时另起一行写笔记命中数。技术性的 ref 标识直接在审计面板底部展示，支持一键复制。

条目检查器分三块。概览给出来源和动作，相关片段按来源分组、带页码和覆盖度，导出列出这篇文献产生的引用文本。会话里还有一页导出汇总，按格式分段、跨条目去重；失败的导出记录在操作列表中。

顶部状态条显示本地 Zotero 有没有连上。离线时给出排查提示，可以就地刷新。当前会话身份缺少 `zotero/status` 权限时，状态条显示无权提示，轨迹中的本地条目仍可查看。

DSH 内建的「轨迹」标签记录工具调用的执行过程；「文献轨迹」专门展示与文献相关的检索、片段和导出成果。

## 使用文献面板

文献面板挂在右侧边栏，与会话并排。文献面板在以下两项均开启时显示：

- 「包含的组件」里 `dsh-zotero/library` 行已启用；
- 组件的 `rightSidebarEnabled` 开启。

`webEnabled` 控制会话顶部的文献轨迹；文献面板由 `rightSidebarEnabled` 控制。

导航区支持多库切换（个人库和群组库）、按需展开的合集树、保存的搜索、「我的出版物」和「回收站」。保存搜索里显示 Zotero 的原始条件。合集行尾显示 Zotero 统计的直接条目数，未上报时不显示。工具栏在库选择器之后提供常驻「解析文档管理」按钮，窄屏也保持这一顺序。按钮打开会话级管理页：每行以解析时抓取的论文标题命名，并显示附件或来源、解析时间、大小与计数。用户可以按状态和关键字筛选，行内打开或重新解析，也可以全选已加载的行后批量删除；删除逐条发起请求，失败项保持选中。列表按「显示更多」增量加载；行间以发丝线分隔，筛选带自带上下的间距与自己的底线，窄屏时元信息让位，行内三个操作始终留在同一行。解析组件提供服务后才会显示按钮和管理页，PDF URL 解析入口位于管理页。

条目列表分页显示，可以切元数据/全文检索模式、五种排序字段和升降序，也能按条目类型、标签（all/any）、年份区间、有没有附件筛选。每行在年份之后依次给出条目类型、期刊或来源与作者：类型名按面板语言渲染，Zotero 未收录的自定义类型用它自己的本地化名；作者取自结构化作者列表，而不是 Zotero 生成的摘要串。当前选中行以背景填充加左侧主色细条标出，指针移开或滚动结束后仍可辨认。行尾的 PDF 徽标表示该条目的最佳附件为 PDF 格式。

检查器头部有类型、标题、作者、来源和年份。动作行能阅读 PDF、提问、加入对话、复制引用或 BibTeX、打开更多格式（参考文献表、BibLaTeX、RIS、CSL-JSON、复制条目信息），也能复制 Zotero 链接。摘要按正文排版显示；超过六行时默认收窄为六行，并在正文下方提供独立的展开/收起，正文本身放得下时不出现该控件。下面的信息表、合集与标签 chips、笔记/附件/标注三个子集合分别分页；各区块之间以发丝线分隔，标题与正文共用同一条左边界。

复制引用和 `zotero_export` 同源，样式与语言沿用配置默认值。BibTeX 可以直接用于 LaTeX，引用键随词条一起输出。复制失败时在动作行就地显示原因。

本地附件在所属会话的右侧阅读栏打开，URL 附件开在浏览器新标签；被宿主拒绝时降级成行内提示。面板属于当前标签页的会话，所以写入的审批和计划卡也发往这个会话。

面板在连接建立后加载数据；离线时显示排查说明，连接恢复后自动重新请求。

宽屏是三列并排（导航、列表、详情），窄屏切成分段导航。面板按 Zotero 实例记住选中的条目和当前分段。

面板用于浏览与检索本地库。外部文献由 Agent 通过学术检索组件查询，保存入库后即可在面板与轨迹中查看。

## 写入文献库（可选）

写入工具默认关闭。在设置里开启 `writeEnabled` 后，注册 15 个只写个人库（`zotero://user/0/`）的工具：

| 类别       | 工具                                                                                     | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 笔记       | `zotero_create_note`、`zotero_update_note`                                               | 创建独立笔记或子笔记，支持标签、合集与 `dc:relation`；更新按版本前置替换正文 |
| 标签与归属 | `zotero_update_item_tags`、`zotero_update_item_collections`                              | 一次调用内读、合并、写回，保留既有标签类型；名称解析失败先于任何写入         |
| 合集       | `zotero_create_collection`、`zotero_update_collection`、`zotero_delete_collection`       | 同级同名拒绝；删除不可逆，计划卡先给出条目数和子合集数                       |
| 条目       | `zotero_create_item`、`zotero_update_item`、`zotero_restore_items`                       | 建立条目、订正标量元数据、从回收站恢复                                       |
| 保存搜索   | `zotero_create_saved_search`、`zotero_update_saved_search`、`zotero_delete_saved_search` | 管理保存搜索定义                                                             |
| 库级标签   | `zotero_delete_library_tags`                                                             | 按名称全库删除标签，不可逆；没命中的名称被忽略，重试幂等                     |
| 批量       | `zotero_batch_items`                                                                     | 单次调用里批量创建、更新标签或归属、移入回收站，合并为一张计划卡             |

每次写入都要过能力检查、会话审批和计划审查卡。不可逆操作在计划卡上先声明影响范围。提交结果未核验时显示「已提交未确认」。面板里的写入和 Agent 写入走同一条路，区别只在谁触发；面板写入要求所属会话正在运行。

## 学术检索（可选组件）

学术检索由 `dsh-zotero/scholarly` 组件提供，随包发布，默认关闭。启用后注册 7 个外部检索工具：索引检索访问白名单内的学术平台，开放获取 PDF 全文下载访问公网 HTTP(S) 主机（支持本机代理与 fake-IP 映射，明文 HTTP 目标要求真实公网地址）。组件首次在客户端启用时会弹出外发提醒，说明检索词与标识符涉及的目标主机。

- 检索覆盖 arXiv、OpenAlex、Crossref、Semantic Scholar、PubMed、Europe PMC 和 DBLP，结果按相关度融合去重，并标出「已在本地库」。
- 能按 DOI、arXiv ID、PMID、PMCID 读开放获取全文并做段落定位，也能追踪引文网络。
- 引用格式从 DOI 注册中心取；核验参考文献列表时，结论分「已核实」「需人工确认」「注册表说没有」「无法核验」四种。
- 用户明确要求时，把外部结果保存到本地个人库。保存之后，它才进入 Zotero 文献库和文献轨迹。

外部检索通过 Agent 工具调用执行。文献面板在开启 `allowUrlPdfRead` 后支持下载库内已有的 URL 附件 PDF。

## 文档解析（可选组件）

文档解析由 `dsh-zotero/enrichment` 组件提供，随包发布，默认关闭。组件支持主动解析 PDF、已有 Markdown 产物复用，以及本地语义排序与模型管理。用户可在文献面板中针对指定的 Zotero PDF 附件或公开 PDF URL 提交解析任务；首次启用时客户端会显示外发解析提醒。

- `free` 使用轻量接口（≤10 MB、≤20 页，免 Token），`pro` 使用精准接口（≤200 MB、≤200 页，需 Token）；接口模式与 Token 独立配置。解析失败时直接返回错误信息。
- `zotero_retrieve` 与 `scholarly_read` 通过核心只读的 `FulltextEnhancer.lookup`（按来源）与 `lookupArtifact`（按产物 id）查询有效 Markdown 产物并优先使用；未命中或源文件变更时，分别回退至 Zotero `/fulltext` 与学术 PDF 本地抽取。
- 解析后的 Markdown 存储在 `<outputDir>/<sha256>/`，Markdown 引用的插图按原文件名存放在同目录的 `images/` 下。本地附件按大小、修改时间与内容指纹缓存；URL 来源通过 HEAD 请求校验 ETag 或 Last-Modified。源索引命中时直接复用既有产物。
- 解析成功且产物仍有效时，条目动作行中的「解析此 PDF」变为「阅读 Markdown」。点击后在右侧边栏打开以论文标题命名的解析结果标签页，显示准备进度；全文与全部产物插图准备完成后一次呈现，并提供完整 Markdown 的复制和下载。刷新失败时保留上一份完整结果。条目带多个 PDF 时，「阅读 PDF」和解析动作共用选择框，并为每个 PDF 标注状态：已有产物的 PDF 打开解析结果，其余提交对应附件的解析。在正文里选中一段，选段旁会浮出小菜单：「让模型解释」把选段、论文标题/作者/来源/DOI 和条目 ref 一并写进当前会话草稿，模型可据此取全文做整体判断；「复制选中内容」写入剪贴板。
- 输出目录支持绝对路径或 `~/`；相对路径在保存时拒绝，目录不可用时解析返回 `ZOTERO_ENRICHMENT_OUTPUT_INVALID`。
- 本地向量语义排序提供语义化档位解耦的开源本地嵌入模型（`balanced` 通用平衡默认推荐 · 基于 Qwen3-0.6B、`lightweight` 极速轻量 · 基于 Granite-97M、`bilingual` 中英双语 · 基于 KaLM-0.5B、`english` 英文长文 · 基于 Nomic-137M、`hybrid` 多路混合 · 基于 BGE-M3、`academic` 经典学术 · 基于 GTE-Base）。配置与物理模型版本解耦。WASM 推理运行时随插件一起发布，模型需在设置中下载（支持 HF-Mirror 镜像与 Hugging Face 直连），在 16GB 内存 CPU 设备上运行。语义关闭时使用 BM25 词面排序；开启后若模型未就绪，检索返回 `ZOTERO_ENRICHMENT_SEMANTIC_UNAVAILABLE` 并引导下载。基于六档实际向量的 20 个手工改写回归例中，recall@4 为 55–95%（english 使用 10 个英文例）；这是同组回归测量，完整数据与范围见开发文档。开启语义检索但未下载模型，或选用精准模式未填 Token 时，界面会显示对应状态。

## 能力与工具对照

| 能力                 | 对话（Agent 工具）                               | 文献面板（人）               | 文献轨迹                |
| -------------------- | ------------------------------------------------ | ---------------------------- | ----------------------- |
| 全库浏览与结构       | `zotero_browse`                                  | 合集树、保存搜索、回收站     | 只记录 Agent 读到的结构 |
| 检索                 | `zotero_search`                                  | 条目列表检索与筛选           | 记录检索条件与命中      |
| 详情与笔记/附件/批注 | `zotero_get`                                     | 条目检视与子集合             | 记录被读取的条目与片段  |
| 原文片段             | `zotero_retrieve`                                | 不提供                       | 记录片段与来源          |
| 高质量全文（可选）   | `zotero_retrieve`、`scholarly_read` 使用解析结果 | 解析结果标签页（可选段提问） | 记录读取                |
| 定位 PDF             | `zotero_get` (`locations="best"`)                | 阅读 PDF                     | 记录定位结果            |
| 引用与导出           | `zotero_export`                                  | 复制引用、BibTeX 等          | 记录导出产物            |
| 写入                 | 15 个写工具（可选）                              | 受审批写入                   | 不记录                  |
| 库外文献             | 7 个学术检索工具（可选组件）                     | 不提供                       | 保存进库后才出现        |

## 合集导航与状态恢复

文献面板的合集目录支持按层级增量加载，每个分支均可独立展开与重试，文献列表则按页展示。展开带有子合集的节点可继续浏览下级分类；重新打开面板时，系统会自动恢复此前已展开的合集分支与加载状态，并重新解析当前合集的名称与层级链。在切换检索条件或重新选择合集时，列表会即时刷新为最新内容，确保条目视图始终与当前选中范围保持一致。
