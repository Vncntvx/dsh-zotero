# 功能概览

dsh-zotero 把 Zotero 文献库接进 DSH。Agent 在对话里检索、阅读、引用文献，需要时也能写；你在文献面板里浏览整个库、复制引用；文献轨迹则集中展示 Agent 在当前会话中查到的文献、提取的原文片段与导出内容，方便对照核对。三者的分工见[产品模型](product-model.md)。

## 在对话中检索与研读

Agent 有 8 个只读工具，参数和错误码见[工具参考](tools.md)。

- `zotero_search` 默认匹配标题、作者和年份，`everything` 模式连全文索引一起搜。范围可以是整个库、个人出版物、某个合集或某个保存的搜索。第一页会顺带扫笔记正文，命中的笔记条目单列在 `supplemental` 里，不计入分页总数。
- `zotero_browse` 读合集树、标签列表和保存的搜索，单页条数受 `maxBrowseResults` 约束，响应携带总数与游标。
- `zotero_get` 返回标题、作者、年份、期刊、DOI、URL、摘要和独立的 `citationKey`；citekey 来源冲突会显式标记。加上 `include` 可以取子笔记正文、PDF 批注和附件列表。
- `zotero_get_batch` 按输入顺序批量读取最多 50 个已知 ref，每条结果独立报告；单条读取仍用 `zotero_get`。
- `zotero_match_references` 用 DOI、BibTeX 键和文献指纹与本地库对账，返回 ref、citekey、置信度和可审阅的字段差异；citekey 冲突不会被静默选中。
- `zotero_retrieve` 从批注、笔记、摘要和全文索引里找片段，用 BM25 词频排序。每条片段带来源和页码标签，页码只有批注才有，取自 Zotero；命中落在正文还是批注评论会标出来。全文覆盖度放在 `coverage`，没建索引或读不到的来源记进 `sourcesSkipped`，附件状态分 `indexed`、`unindexed`、`unread`。
- `zotero_export` 支持六种格式。除 `citation` 外，单次最多 50 篇，这是 Zotero `itemKey` 的请求上限；`citation` 按 50 一组分批。

  | 格式                  | 输出                                       |
  | --------------------- | ------------------------------------------ |
  | `citation`            | 逐条 HTML 引用，按输入顺序                 |
  | `bibliography`        | CSL 排序的合并参考文献表                   |
  | `bibtex` / `biblatex` | BibTeX / BibLaTeX 词条，能定位每条的引用键 |
  | `ris` / `csljson`     | RIS 文本 / CSL-JSON                        |

  样式和语言默认取配置里的 `defaultStyle` 和 `defaultLocale`，可以用 `style`、`locale` 覆盖。

- `zotero_changes` 从本地库版本号出发，报告新增、修改和删除，回收站单独算一块。

工具结果在对话里是只读卡片。折叠时一行摘要，展开后按工具类型显示条目、片段、导出文本或回执，能复制，也能点「阅读 PDF」。卡片只渲染工具已经产生的输出，自己不会再调工具。

研究 SOP 技能提供七个按需研究流程：主题版图、引文脉络、证据比较、写作对账、文库治理、真伪审查与文献入库。模型先从只含名称与短描述的目录中选择，再经 `skill` 工具加载完整分阶段指令；正文不进入常驻 system prompt。详见[研究 SOP 技能参考](skills.md)。

## 核对文献轨迹

文献轨迹在会话顶部，把本会话里 Agent 检索到、读过的文献按条目聚在一起。数据来自宿主按整份会话日志折叠的会话投影，长会话不会因为历史窗口截断而丢掉早期条目；投影不可用时回退到当前已加载窗口的工具调用快照。切过去不会新发请求。

它记录读类工具和导出的结果。写入不进轨迹，修改有自己的卡片和审批记录；学术检索的结果要等保存进库才出现。

每次检索的条件直接摆在首屏：查询词、范围（库、个人出版物、合集、保存的搜索）、模式（元数据或全文）、筛选（条目类型、标签、回收站），以及返回条数和总数。扫过笔记时另起一行写笔记命中数。技术性的 ref 标识直接在审计面板底部展示，支持一键复制。

条目检查器分三块。概览给出来源和动作，相关片段按来源分组、带页码和覆盖度，导出列出这篇文献产生的引用文本。会话里还有一页导出汇总，按格式分段、跨条目去重；失败的导出调用单独列在操作里，不算成果。

顶部状态条显示本地 Zotero 有没有连上。离线时给出排查提示，可以就地刷新。当前会话身份没有 `zotero/status` 访问权时，状态条只显示无权提示，不发探测请求；轨迹里的本地条目仍可查看。

DSH 内建的「轨迹」标签显示工具调用的执行过程。文献轨迹只看与文献有关的结果。

## 使用文献面板

文献面板挂在右侧边栏，与会话并排。下面三处都打开才会出现：

- 「包含的组件」里 `dsh-zotero/library` 行已启用；
- 核心 `webEnabled` 开启；
- 组件的 `rightSidebarEnabled` 开启。

导航区支持多库切换（个人库和群组库）、按需展开的合集树、保存的搜索、「我的出版物」和「回收站」。保存搜索里显示 Zotero 的原始条件。

条目列表分页显示，可以切元数据/全文检索模式、五种排序字段和升降序，也能按条目类型、标签（all/any）、年份区间、有没有附件筛选。行尾的 PDF 徽标表示检索命中里最佳附件是 PDF；没有徽标不代表条目没有文件。

检查器头部有类型、标题、作者、来源和年份。动作行能阅读 PDF、提问、加入对话、复制引用或 BibTeX、打开更多格式（参考文献表、BibLaTeX、RIS、CSL-JSON、复制条目信息），也能复制 Zotero 链接。下面的信息表、合集与标签 chips、笔记/附件/标注三个子集合分别分页。

复制引用和 `zotero_export` 同源，样式与语言沿用配置默认值。BibTeX 可以直接用于 LaTeX，引用键随词条一起输出。复制失败会在动作行里就地显示原因，不会自动重试。

本地附件在所属会话的右侧阅读栏打开，URL 附件开在浏览器新标签；被宿主拒绝时降级成行内提示。面板属于当前标签页的会话，所以写入的审批和计划卡也发往这个会话。

面板打开并确认连接后才发请求，关闭后不再发新请求。探针离线时，工具栏以下换成离线说明，连接恢复前不发请求。

宽屏是三列并排（导航、列表、详情），窄屏切成分段导航。面板按 Zotero 实例记住选中的条目和当前分段。

面板只检索本地库。库外文献由 Agent 用学术检索组件查找，存进库之后才会出现在面板和轨迹里。

## 写入文献库（可选）

写入工具默认关闭。在设置里开启 `writeEnabled` 后，注册 15 个只写个人库（`zotero://user/0/`）的工具：

| 类别       | 工具                                                                                     | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 笔记       | `zotero_create_note`、`zotero_update_note`                                               | 创建独立笔记或子笔记，支持标签、合集与 `dc:relation`；更新按版本前置替换正文 |
| 标签与归属 | `zotero_update_item_tags`、`zotero_update_item_collections`                              | 一次调用内读、合并、写回，保留既有标签类型；名称解析失败先于任何写入         |
| 合集       | `zotero_create_collection`、`zotero_update_collection`、`zotero_delete_collection`       | 同级同名拒绝；删除不可逆，计划卡先给出条目数和子合集数                       |
| 条目       | `zotero_create_item`、`zotero_update_item`、`zotero_restore_items`                       | 建立条目、订正标量元数据、从回收站恢复                                       |
| 保存搜索   | `zotero_create_saved_search`、`zotero_update_saved_search`、`zotero_delete_saved_search` | 管理保存搜索定义                                                             |
| 库级标签   | `zotero_delete_library_tags`                                                             | 按名称全库删除标签，不可逆；没命中的名称被忽略，重试幂等                     |
| 批量       | `zotero_batch_items`                                                                     | 单次调用里批量创建、更新标签或归属、移入回收站，合并为一张计划卡             |

每次写入都要过能力检查、会话审批和计划审查卡。不可逆操作在计划卡上先声明影响范围。提交结果没核验时显示「已提交未确认」，不显示成功。面板里的写入和 Agent 写入走同一条路，区别只在谁触发；面板写入要求所属会话正在运行。

## 学术检索（可选组件）

学术检索由 `dsh-zotero/scholarly` 组件提供，随包发布但默认关闭。启用这个组件行就是授权：启用后注册 7 个工具——索引检索仅限白名单里的外部学术索引，开放获取 PDF 全文臂是唯一例外（任意公网 HTTP(S) 主机，受公网地址双门校验）；不启用，这些工具不存在，也不会发起学术检索请求。

- 检索覆盖 arXiv、OpenAlex、Crossref、Semantic Scholar、PubMed、Europe PMC 和 DBLP，结果按相关度融合去重，并标出「已在本地库」。
- 能按 DOI、arXiv ID、PMID、PMCID 读开放获取全文并做段落定位，也能追踪引文网络。
- 引用格式从 DOI 注册中心取；核验参考文献列表时，结论分「已核实」「需人工确认」「注册表说没有」「无法核验」四种。
- 用户明确要求时，把外部结果保存到本地个人库。保存之后，它才进入 Zotero 文献库和文献轨迹。

外部检索属于 Agent 入口。文献面板仅在独立开启 `allowUrlPdfRead` 后，响应用户点击下载库内已有 URL 附件的 PDF；不会执行外部检索。

## 文档解析（可选组件）

文档解析由 `dsh-zotero/enrichment` 组件提供，随包发布，默认关闭。启用组件即接受 MinerU 文档外发，并提供主动解析、已有产物只读复用、本地语义排序与模型管理；客户端在启用时显示一次提醒。组件不注册模型工具、不注入提示词段。用户针对一个具体 Zotero PDF 附件（子附件或顶层附件）或一个公开 PDF URL 提交，宿主检查远程动作与会话访问权限。普通读取、PDF 打开、设置保存和服务启动不提交、恢复或上传 MinerU 任务。

- `free` 使用免 Token 的 Agent 轻量接口（API 侧 ≤10 MB、≤20 页），`pro` 使用精准接口（API 侧 ≤200 MB、≤200 页）并需要 Token；接口模式与是否配置 Token 相互独立。解析失败时不切换模式，也不以本地抽取文本冒充成功。
- 普通 `zotero_retrieve` 与 `scholarly_read` 通过核心只读 `FulltextEnhancer.lookup` 查询同一来源、仍有效的 Markdown；命中时优先使用，包括有效短文档。无产物或源已变化时记为未命中，本地读取继续走 Zotero `/fulltext`，学术读取沿已获准的 PDF 下载与本地抽取；权限、I/O、协议损坏等故障按错误处理，不记为未命中。已有且有效的产物始终可读取。
- 解析 Markdown 落在 `<outputDir>/<sha256>/`；本地附件按大小/修改时间 + 内容指纹缓存，URL 源按 URL 缓存并用一次不带 token 的 HEAD 校验；源索引命中要求匹配 ETag，或同时匹配 Last-Modified 与 Content-Length；`lookup` 先查源索引，命中时不下载 PDF、不联系 MinerU。来源元数据不保存 URL 的 query/fragment；私有任务回执只在上传完成前暂存签名地址。
- 输出目录支持绝对路径或 `~/`；相对路径在保存时拒绝，不存在/不可写/敏感目录在首次解析时以 `ZOTERO_ENRICHMENT_OUTPUT_INVALID` 失败。
- 本地向量语义排序提供语义化档位解耦的开源本地嵌入模型（`balanced` 通用平衡默认推荐 · 基于 Qwen3-0.6B、`lightweight` 极速轻量 · 基于 Granite-97M、`bilingual` 中英双语 · 基于 KaLM-0.5B、`english` 英文长文 · 基于 Nomic-137M、`hybrid` 多路混合 · 基于 BGE-M3、`academic` 经典学术 · 基于 GTE-Base）。配置与物理模型版本解耦，模型升级时配置保持不变。模型需手动下载后启用（支持 HF-Mirror 镜像与 Hugging Face 直连）。关闭语义时使用完整 BM25 词面排序；开启但所选模型缺失、损坏或本地推理运行时不可用时，读取以 `ZOTERO_ENRICHMENT_SEMANTIC_UNAVAILABLE` 失败并提示下载，不降级为词面结果。模型参数量 100M~600M，面向 16GB 内存、纯 CPU 设备。六档模型均已实机验证：零实词重合的改写提问下语义 recall@4 为 58–96%，无关语料不产生语义命中。开启语义检索但未下载模型，或选用精准解析模式但未配置 Token 时，界面显示提示。

## 能力与工具对照

| 能力                 | 对话（Agent 工具）                               | 文献面板（人）           | 文献轨迹                |
| -------------------- | ------------------------------------------------ | ------------------------ | ----------------------- |
| 全库浏览与结构       | `zotero_browse`                                  | 合集树、保存搜索、回收站 | 只记录 Agent 读到的结构 |
| 检索                 | `zotero_search`                                  | 条目列表检索与筛选       | 记录检索条件与命中      |
| 详情与笔记/附件/批注 | `zotero_get`                                     | 条目检视与子集合         | 记录被读取的条目与片段  |
| 原文片段             | `zotero_retrieve`                                | 不提供                   | 记录片段与来源          |
| 高质量全文（可选）   | `zotero_retrieve`、`scholarly_read` 使用解析结果 | 不提供                   | 记录读取                |
| 定位 PDF             | `zotero_get` (`locations="best"`)                | 阅读 PDF                 | 记录定位结果            |
| 引用与导出           | `zotero_export`                                  | 复制引用、BibTeX 等      | 记录导出产物            |
| 写入                 | 15 个写工具（可选）                              | 受审批写入               | 不记录                  |
| 库外文献             | 7 个学术检索工具（可选组件）                     | 不提供                   | 保存进库后才出现        |

## 合集导航与状态恢复

文献面板的合集目录支持按层级增量加载，每个分支均可独立展开与重试，文献列表则按页展示。展开带有子合集的节点可继续浏览下级分类；重新打开面板时，系统会自动恢复此前已展开的合集分支与加载状态，并重新解析当前合集的名称与层级链。在切换检索条件或重新选择合集时，列表会即时刷新为最新内容，确保条目视图始终与当前选中范围保持一致。
