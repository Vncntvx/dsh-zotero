- **核心组件**（`dsh-zotero`）：本机 Zotero 连接、8 个读工具与 15 个写工具（默认关闭，启用后每次写入都需在计划审查卡中确认）、文献轨迹与设置页。
- **文献面板**（`dsh-zotero/library`）：右侧边栏标签页，覆盖全库导航（合集树、保存的搜索、我的出版物、回收站）、条目列表筛选、条目检视、复制引用（CSL 引文、BibTeX、参考文献表、BibLaTeX、RIS、CSL-JSON 与条目信息）以及经审批的受控写入。
- **学术检索**（`dsh-zotero/scholarly`）：外部文献检索组件，默认关闭；组件挂载即授权对外部学术索引的请求，客户端在组件处于已启用状态且本机尚未确认时提示请求范围，确认只覆盖当前这次启用，组件关闭后再启用会重新提示。覆盖 arXiv、OpenAlex、Crossref、Semantic Scholar、PubMed、Europe PMC 与 DBLP，支持全文读取、引文网络、参考文献核验与保存到 Zotero。
- **文档解析**（`dsh-zotero/enrichment`）：可选组件，默认关闭；启用即接受 MinerU 文档外发；客户端在组件处于已启用状态且本机尚未确认时提示外发范围，确认只覆盖当前这次启用，组件关闭后再启用会重新提示。提供主动解析、已有产物复用和本地语义检索 / 模型管理，不注册模型工具或提示词段。支持免 Token 的 `free` 和需 Token 的 `pro`，Markdown 产物保存到可配置目录。
